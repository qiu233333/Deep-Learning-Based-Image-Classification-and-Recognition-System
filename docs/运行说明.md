# 系统运行说明

## 1. 环境要求
- 操作系统：macOS / Windows / Linux（本项目在 Apple M5 + macOS 上开发测试）
- Python 3.9+（推荐 3.11）
- 依赖安装：`pip install -r requirements.txt`（PyTorch 请安装支持本机硬件的版本）

## 2. 一键启动
```bash
cd 智能系统设计与实践
python app/app.py
```
启动成功后终端显示：`Running on http://127.0.0.1:8000`

- 识别台：http://127.0.0.1:8000/ （上传图像 → 选择模型 → 识别）
- 管理后台：http://127.0.0.1:8000/admin （数据集概况 / 在线训练 / 识别记录与特征）

## 3. 数据集
- 已构建好的数据集位于 `data/flower102/`（102 类，6:2:2 划分，共 8189 张）。
- 如需重建：先下载 `102flowers.tgz`（约 329MB）与 `imagelabels.mat`
  （https://www.robots.ox.ac.uk/~vgg/data/flowers/102/）放入 `data/`，再执行
  `python scripts/build_dataset.py`。

## 4. 模型
- 已训练权重位于 `models/`：resnet18 / resnet34 / mobilenet_v3_large / efficientnet_b0 各一个 `*_best.pt`。
- 重新训练：`python scripts/train.py --model resnet18 --epochs 15`
- 在线训练：在管理后台“模型训练与微调”面板选择模型与轮数，点击“启动训练”。

## 5. 评估与图表
```bash
python scripts/evaluate.py --models resnet18,resnet34,mobilenet_v3_large,efficientnet_b0
python scripts/make_figures_extra.py   # 数据示例图与预测样例图
```
评估指标写入 `results/`，图表输出至 `figures/`。

## 6. 演示视频
`runs/demo.mp4` 为系统完整演示视频（由 Playwright 自动化录制）。
页面截图位于 `runs/screens/`。

## 7. 常见问题
- 若端口被占用：修改 `app/app.py` 中 `port=8000` 为其他端口。
- 若本机无 Apple 芯片：自动回退 CPU 推理（代码中已处理 mps 不可用的情况）。
- 目录会自动加载模型：把 `*_best.pt` 放入 `models/` 后重启服务即可。
